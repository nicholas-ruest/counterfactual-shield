# DDD-0011: Recovery
## Bounded context
Owns RecoveryPlan and Compensation.
## Ubiquitous language
Uses canonical terms and no ambiguous safety booleans.
## Aggregates, entities, and value objects
RecoveryPlan and Compensation. IDs and scores are immutable; lifecycle belongs to the aggregate root.
## Invariants
reverse order; visible failures.
## Domain events
Publishes RecoveryCompleted or RecoveryPartial.
## Context map
Facts cross owned ports; infrastructure adapters translate Cedar, RuVector and RVF.
## Ports and adapters
Infrastructure cannot gain authority beyond the typed result.
## Acceptance
Unit invariants plus a real orchestration or integration caller exercise this context.
