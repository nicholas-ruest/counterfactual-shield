# DDD-0012: Operations
## Bounded context
Owns Scenario, report, metrics and config.
## Ubiquitous language
Uses canonical terms and no ambiguous safety booleans.
## Aggregates, entities, and value objects
Scenario, report, metrics and config. IDs and scores are immutable; lifecycle belongs to the aggregate root.
## Invariants
claims bind source, seed, mode and receipts.
## Domain events
Publishes EvaluationCompleted.
## Context map
Facts cross owned ports; infrastructure adapters translate Cedar, RuVector and RVF.
## Ports and adapters
Infrastructure cannot gain authority beyond the typed result.
## Acceptance
Unit invariants plus a real orchestration or integration caller exercise this context.
