# DDD-0003: Graph
## Bounded context
Owns ResourceGraph and edges.
## Ubiquitous language
Uses canonical terms and no ambiguous safety booleans.
## Aggregates, entities, and value objects
ResourceGraph and edges. IDs and scores are immutable; lifecycle belongs to the aggregate root.
## Invariants
bounded cycle-safe traversal.
## Domain events
Publishes GraphSnapshotReady.
## Context map
Facts cross owned ports; infrastructure adapters translate Cedar, RuVector and RVF.
## Ports and adapters
Infrastructure cannot gain authority beyond the typed result.
## Acceptance
Unit invariants plus a real orchestration or integration caller exercise this context.


## Detailed domain model
ResourceGraph owns resource nodes, directed exposure edges, and bounded criticality. It consumes accepted actions but does not authorize them. Reachability is a domain service because exposure can cross many resources without changing the ActionBatch aggregate. GraphEvaluated supplies CriticalReach to the causal context.

## Ownership and collaboration
cs-resource-graph is upstream of cs-counterfactual and has no infrastructure dependency. The graph context exports facts through typed values and never leaks infrastructure handles across the context map. Commands are validated by the owning aggregate; downstream contexts consume immutable results. Failures remain explicit and are not converted into permissive booleans.

## Scenario acceptance
The frozen three-action deployment scenario must cross this context through its public API. Its unit invariant and at least one upstream or downstream collaboration are exercised by locked workspace tests; removing the context must create an observable ablation or eliminate a required release condition.
