# ADR-0015: Telemetry
Status: Accepted
## Context
We need secret-free observation with prospective safety, deterministic evidence and explicit authority.
## Viable alternatives
- logs
- payload traces
## Decision
Use structured counters and buckets.
## Tradeoffs
less payload detail.
## Consequences
This boundary participates in the grant decision and fails closed. Downstream contexts receive typed results rather than ambiguous flags.
## Validation
Validate with redaction, bound to the exact candidate commit.
