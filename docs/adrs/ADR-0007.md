# ADR-0007: Evidence
Status: Accepted
## Context
We need tamper detection with prospective safety, deterministic evidence and explicit authority.
## Viable alternatives
- JSON hash
- audit DB
## Decision
Use RVF witness chain.
## Tradeoffs
integrity not truth.
## Consequences
This boundary participates in the grant decision and fails closed. Downstream contexts receive typed results rather than ambiguous flags.
## Validation
Validate with verify and tamper reject, bound to the exact candidate commit.
