# ADR-0016: API
Status: Accepted
## Context
We need stable contract with prospective safety, deterministic evidence and explicit authority.
## Viable alternatives
- direct crates
- REST daemon
## Decision
Use typed service facade.
## Tradeoffs
no network v1.
## Consequences
This boundary participates in the grant decision and fails closed. Downstream contexts receive typed results rather than ambiguous flags.
## Validation
Validate with vertical slice, bound to the exact candidate commit.
