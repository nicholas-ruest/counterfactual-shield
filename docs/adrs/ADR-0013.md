# ADR-0013: Timeouts
Status: Accepted
## Context
We need bounded upstream work with prospective safety, deterministic evidence and explicit authority.
## Viable alternatives
- unbounded
- global timeout
## Decision
Use per-stage budgets.
## Tradeoffs
slow valid work may fail.
## Consequences
This boundary participates in the grant decision and fails closed. Downstream contexts receive typed results rather than ambiguous flags.
## Validation
Validate with timeout paths, bound to the exact candidate commit.
