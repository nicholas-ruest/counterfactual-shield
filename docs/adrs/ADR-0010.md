# ADR-0010: Grant
Status: Accepted
## Context
We need analysis versus authority with prospective safety, deterministic evidence and explicit authority.
## Viable alternatives
- boolean
- bearer token
## Decision
Use nonce-bound ExecutionGrant.
## Tradeoffs
nonce state.
## Consequences
This boundary participates in the grant decision and fails closed. Downstream contexts receive typed results rather than ambiguous flags.
## Validation
Validate with replay reject, bound to the exact candidate commit.
