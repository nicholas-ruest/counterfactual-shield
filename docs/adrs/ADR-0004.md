# ADR-0004: Interventions
Status: Accepted
## Context
We need causal responsibility with prospective safety, deterministic evidence and explicit authority.
## Viable alternatives
- correlation
- full SCM
## Decision
Use remove-one-action counterfactuals.
## Tradeoffs
local approximation.
## Consequences
This boundary participates in the grant decision and fails closed. Downstream contexts receive typed results rather than ambiguous flags.
## Validation
Validate with known graph fixtures, bound to the exact candidate commit.


## Detailed rationale
Responsibility is estimated by removing one action at a time and recomputing critical reach while keeping the remaining batch and graph fixed. Correlation-only attribution was rejected because repeated verbs or similar embeddings do not establish marginal blast contribution. This mechanism changes mitigation order and therefore changes the grant evidence.

## Executed boundary and proof
The interventions decision is implemented as a typed boundary, not a documentation-only convention. cs-counterfactual and cs-attribution tests; the mitigation plan must select a positive-reduction action.

## Review trigger
Revisit this decision if its upstream API, trust boundary, workload distribution, or failure semantics change. A revision must preserve fail-closed authorization, deterministic replay, and an ablation that demonstrates what capability the decision contributes.
