# ADR-0011: Ledger
Status: Accepted
## Context
We need audit ownership with prospective safety, deterministic evidence and explicit authority.
## Viable alternatives
- mutable DB
- logs
## Decision
Use append-only hash-linked records.
## Tradeoffs
checkpoint compaction.
## Consequences
This boundary participates in the grant decision and fails closed. Downstream contexts receive typed results rather than ambiguous flags.
## Validation
Validate with corruption reject, bound to the exact candidate commit.
