# ADR-0002: Action batch
Status: Accepted
## Context
We need intent and order with prospective safety, deterministic evidence and explicit authority.
## Viable alternatives
- flat events
- opaque transcript
## Decision
Use validated action DAG.
## Tradeoffs
early rejection.
## Consequences
This boundary participates in the grant decision and fails closed. Downstream contexts receive typed results rather than ambiguous flags.
## Validation
Validate with cycles, duplicates and missing parents, bound to the exact candidate commit.
