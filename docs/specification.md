# Specification
## Problem
Autonomous agents can combine plausible tool calls into a chain whose blast radius reaches critical data, identity, deployment or financial resources. Static authorization sees one request; post-hoc provenance sees damage.
## Users
Platform security, agent-runtime owners, SREs and regulated automation operators.
## Capability
Issue a single-use grant only after Cedar authorization, RuVector incident recall, counterfactual blast attribution, conformal risk control, budgeted mitigation and RVF evidence verification.
## Workload
An infrastructure agent proposes reading a production secret, updating IAM, deploying a container and rotating a database. Validate the DAG, map critical reachability, recall incidents, simulate removal/failure, authorize, certify risk, plan mitigation, seal and grant or deny.
## Success
Deny forbidden chains; rank responsible actions; reduce critical reachability under budget; release only at upper risk <= 0.35; recall incidents; reject tampering/replay; prove ablation losses; pass locked quality and exact-main CI.
## Constraints
No actual tool execution. Upstream content is untrusted. Conformal validity assumes exchangeability. RVF proves integrity, not truth.
